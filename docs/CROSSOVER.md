# Radiologist review

Share the [senior reader link](https://jwang1402.github.io/ct-report-review/#/senior) with the two senior radiologists and the [junior reader link](https://jwang1402.github.io/ct-report-review/#/junior) with the three junior radiologists. Each reader enters their name. Seniors choose Study A or Study B. Juniors go directly to Study B.

Enter your name and select **Continue**. The same name in the same reader group resumes your saved work on any browser. If the name has no match, a recognized browser restores its reader’s record under the saved name. Sign out before handing a computer to someone else. This clears the browser’s reader association and keeps your study progress. Coordinators can correct a saved name in [Reader access](https://jwang1402.github.io/ct-report-review/#/admin/reader-access).

## Study A

Each senior independently rates three anonymously lettered reports for each of ten CT examinations. Each report has its own 18-finding checklist, overall quality rating and error record. Record each clinically important missed, unsupported or incorrectly located finding, including the side or location when relevant.

In [Study A results](https://jwang1402.github.io/ct-report-review/#/admin/results), the coordinator can enter the independent case reference, view progress and export reviews, individual errors or finding-level comparisons. **Show model names** reveals each case’s report key and the matched comparison across the three models. Finding-level exports distinguish a missing reference, an indeterminate finding and a confirmed absence. Reader-identified errors remain separate from checklist comparisons.

## Prepare Study B

1. Open [Upload Case → Study B](https://jwang1402.github.io/ct-report-review/#/admin/upload?study=B). **Upload complete · 10/10 cases uploaded** means all ten CT links and their MORPH-CT drafts are saved. Select **View cases** to review them.
2. For a new upload, select **Choose Study B files** and choose `Study_B_Upload.zip`. Confirm the scans are approved for sharing, select **Connect Google Drive**, then **Choose folder**. Use a dedicated folder set to **Anyone with the link → Viewer**. Select **Upload Study B**. The site verifies the CTs and saves them with the drafts. If a transfer stops, select the same package and folder to reuse completed files. If only the website save fails, select **Retry save**.
3. Once all ten CTs and original MORPH-CT drafts are saved, select **Open Study B to readers**. Opening fixes the scans, original drafts and crossover order. The independent expert reference field can stay empty while readers complete their assigned examinations.
4. Before assessing a submitted report, select its case in [Study B administration](https://jwang1402.github.io/ct-report-review/#/admin/upload?study=B), enter the independent expert reference and select **Save reference**. Enter key findings and any known errors in the original draft. A normal examination can have an expert reference with no positive key findings. The first saved assessment locks that case’s reference and associated items for subsequent assessments. Record the study's case mix, reader experience, model settings, prompts and generation dates in the study records.

## Study B readings and results

Each senior writes one unaided report for each CT. Each junior reads all ten CTs twice. In the first session, each junior can consult a MORPH-CT draft for five cases and reads the other five independently. The second session reverses the condition for each case. It becomes available 28 days after the junior's final submission in the first session and requires a new name confirmation.

Senior and junior readers both enter Study B through its workspace, which lists cases B01–B10 in numeric order and shows reading progress. Select a case to preview it, then choose **Open CT** when ready. Timing begins when the CT is opened and runs until final submission, including image loading, breaks and editing. Select **Save draft** before returning to the workspace to resume the report later. Submit the current reading before opening another CT.

**Final report** starts blank in both conditions. During an assisted reading, the original **MORPH-CT draft** appears above the editor as a read-only reference. Readers can copy passages manually. When they resume a reading, the editor restores their saved text. Readers record their own present/absent findings and applicable laterality before submitting their final report.

In **Readings and results**, use the independent reference to assess each final report. For each AI-assisted report, record which errors in the original draft were retained. The export includes the readings, timing, reader and case identifiers, assessments and paired analysis. Agreement uses the same cases and the same three juniors in both conditions. Reporting time uses paired readings by case and reader. Incomplete pairs and unassessed outcomes remain distinguishable from zero errors.

To remove a Study B reading, open **Results → Study B**, find the reader, case and session, then choose **Delete** on that row. Confirming permanently removes that reading’s report, findings, timing and any linked assessment from the results.

If practice is approved, use two separate practice examinations before timed Study B readings. Keep practice cases and submissions outside the ten scored cases.
